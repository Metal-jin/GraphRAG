# 金庸武侠知识图谱本体（ontology）

> 本文件定义：我们从金庸小说文本里**抽取哪些实体类型**和**关系类型**。
> 这是 B 同学写抽取逻辑（build_kg.py）的依据，也是 C、D 检索、E1 评测的基础。
> 初版由组长提供，B 同学负责最终定稿。**改动必须通知全组。**

---

## 一、实体类型（Entity Types）

| 中文标签 | 说明 | 例子 |
|---|---|---|
| 人物 | 小说中的角色 | 郭靖、黄蓉、杨过、小龙女、洪七公、黄药师 |
| 门派 | 武林门派/组织 | 全真教、丐帮、桃花岛、古墓派、白驼山 |
| 武功 | 武功招式/秘籍 | 降龙十八掌、九阴真经、打狗棒法、蛤蟆功 |
| 地点 | 地名/场所 | 襄阳、桃花岛、终南山、华山、大理 |

> 说明：先做这 4 类，够用。如果后续发现需要"物品"（如打狗棒、玄铁重剑），再加。

---

## 二、关系类型（Relationship Types）

关系类型用英文大写命名（Neo4j 惯例）。**方向约定见每条的说明。**

| 关系类型 | 含义 | 方向说明 | 例子 |
|---|---|---|---|
| `MASTER_OF` | 师徒 | A 是 B 的师父：`(A)-[:MASTER_OF]->(B)` | 洪七公 → 郭靖 |
| `SPOUSE_OF` | 夫妻 | 双向，任一方向都可 | 郭靖 ↔ 黄蓉 |
| `PARENT_OF` | 父母子女 | A 是 B 的父母：`(A)-[:PARENT_OF]->(B)` | 黄药师 → 黄蓉 |
| `SWORN_BROTHER_OF` | 结拜 | 双向 | 郭靖 ↔ 周伯通 |
| `ENEMY_OF` | 仇敌 | 双向 | 郭靖 ↔ 欧阳锋 |
| `BELONGS_TO` | 所属门派 | A 属于门派 B：`(A)-[:BELONGS_TO]->(B)` | 郭靖 → 丐帮 |
| `MASTERS` | 精通武功 | A 精通武功 B：`(A)-[:MASTERS]->(B)` | 郭靖 → 降龙十八掌 |
| `FOUNDER_OF` | 创立门派 | A 创立门派 B：`(A)-[:FOUNDER_OF]->(B)` | 王重阳 → 全真教 |
| `LOCATED_IN` | 位于地点 | A 位于地点 B：`(A)-[:LOCATED_IN]->(B)` | 桃花岛 → 东海 |

## 三、抽取示例

假设文本片段是：

> "洪七公是丐帮帮主，他将降龙十八掌传授给郭靖。郭靖后来娶了黄蓉，黄蓉是黄药师的女儿。"

抽取结果应该是：

**实体**：
```json
[
  {"name": "洪七公", "type": "人物"},
  {"name": "郭靖", "type": "人物"},
  {"name": "黄蓉", "type": "人物"},
  {"name": "黄药师", "type": "人物"},
  {"name": "丐帮", "type": "门派"},
  {"name": "降龙十八掌", "type": "武功"}
]
```

**关系**：
```json
[
  {"source": "洪七公", "target": "郭靖", "type": "MASTER_OF"},
  {"source": "洪七公", "target": "丐帮", "type": "BELONGS_TO"},
  {"source": "郭靖", "target": "降龙十八掌", "type": "MASTERS"},
  {"source": "郭靖", "target": "黄蓉", "type": "SPOUSE_OF"},
  {"source": "黄药师", "target": "黄蓉", "type": "PARENT_OF"}
]
```

## 四、注意事项

1. **只抽上面定义的实体类型和关系类型**，不在清单里的不要抽（保证图谱规范）。
2. **同名实体要合并**：同一个"郭靖"只能有一个节点，抽取时用 `MERGE` 合并。
3. **关系方向要对**：师徒、父母、所属、精通、创立、位于都有方向；夫妻、结拜、仇敌是双向。
4. **实体名要规范**：用全称，不要用昵称简称（除非文本里只出现简称）。
